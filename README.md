# Gold Price Watcher — Ethiopia 🇪🇹

Multi-user Ethiopian gold price monitoring service with Telegram alerts and a live web dashboard.

> **Disclaimer:** All prices are reference rates derived from international spot prices
> converted via the live ETB/USD rate. They are **not** dealer quotes.
> Always verify the actual local buying/selling price before making a transaction.

---

## Features

- 🔐 User accounts — register, log in, manage your own settings
- 📊 Live 24K / 22K / 18K gold prices in ETB per gram, with historical chart
- 🤖 Personal Telegram alerts — each user connects their own Telegram chat via a deep-link
- ⏰ Automated price summary every **48 hours** per user (configurable)
- 🚨 Custom alert rules: price above/below threshold, or % change ≥ N%
- 🔄 Manual "Fetch Now" button for an immediate check
- 💤 GitHub Actions keep-alive ping every 14 minutes — prevents free-tier sleep
- 📍 Source + disclaimer always visible in every alert and on the dashboard

## Deploying to Render (recommended free option)

Render gives you a free web service + free static site. The keep-alive
workflow prevents the free tier from sleeping.

### Step 1 — Push to GitHub

```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR_USERNAME/gold-price-watcher.git
git push -u origin main
```

> ⚠️ `.env` is in `.gitignore` — it will never be committed. Good.

### Step 2 — Create a Render account

Go to [render.com](https://render.com) → sign up with your GitHub account.

### Step 3 — Deploy from render.yaml

1. Render Dashboard → **New** → **Blueprint**
2. Connect your GitHub repo
3. Render detects `render.yaml` and shows two services: `gold-price-watcher-api` (backend) and `gold-price-watcher` (frontend)
4. Click **Apply**

### Step 4 — Set secret environment variables

In the Render dashboard → select `gold-price-watcher-api` → **Environment**:

| Key | Value |
|-----|-------|
| `TELEGRAM_BOT_TOKEN` | `8910258528:AAEwHe7DW_GHUyq_...` |
| `TELEGRAM_BOT_USERNAME` | `GoldPriceWatcherBot` |
| `TELEGRAM_WEBHOOK_SECRET` | any random string you choose |
| `SECRET_KEY` | auto-generated by Render or paste your own |

### Step 5 — Register the Telegram webhook

Once the backend is live (e.g. `https://gold-price-watcher-api.onrender.com`):

```bash
curl "https://api.telegram.org/bot8910258528:AAEwHe7DW_GHUyq_a8pQHDUtkuT-9MXcqKQ/setWebhook" \
  -d "url=https://gold-price-watcher-api.onrender.com/api/telegram/webhook" \
  -d "secret_token=YOUR_WEBHOOK_SECRET"
```

You should get: `{"ok":true,"result":true}`

### Step 6 — Update CORS_ORIGINS

In Render → `gold-price-watcher-api` → Environment:

```
CORS_ORIGINS=https://gold-price-watcher.onrender.com
```

Redeploy the backend after saving.

## Deploying to Railway (alternative)

Railway is slightly faster to set up and has a generous free tier.

### Step 1 — Install Railway CLI

```bash
npm install -g @railway/cli
railway login
```

### Step 2 — Deploy backend

```bash
cd backend
railway init        # creates a new project
railway up          # deploys using railway.toml + nixpacks.toml
```

### Step 3 — Set environment variables

```bash
railway variables set TELEGRAM_BOT_TOKEN=8910258528:AAEwHe7DW_GHUyq_a8pQHDUtkuT-9MXcqKQ
railway variables set TELEGRAM_BOT_USERNAME=GoldPriceWatcherBot
railway variables set TELEGRAM_WEBHOOK_SECRET=your-random-string
railway variables set SECRET_KEY=your-secret-key
railway variables set FETCH_INTERVAL_HOURS=12
```

### Step 4 — Get your public URL and register the webhook

```bash
railway open   # opens the dashboard — copy your service URL
```

Then run the same `setWebhook` curl command from Step 5 above using your Railway URL.

### Step 5 — Deploy frontend

The React frontend is a static build — deploy it to **Vercel** (free, recommended):

```bash
cd frontend
npm run build
# Push to GitHub, then connect the repo on vercel.com
# Set root directory to "frontend" and build command to "npm run build"
```

## GitHub Actions Keep-Alive Setup

The workflow in `.github/workflows/keep_alive.yml` pings your backend
every 14 minutes so it never sleeps.

**One-time setup:**

1. GitHub repo → **Settings** → **Secrets and variables** → **Actions**
2. Click **New repository secret**
3. Name: `BACKEND_URL`
4. Value: your full backend URL, e.g. `https://gold-price-watcher-api.onrender.com`
5. Save — the workflow activates on the next push

To test it manually: **Actions** tab → **Keep Alive — Ping Backend** → **Run workflow**.

## How the 48-Hour Alert Works

```
Price job runs every 12 hours (FETCH_INTERVAL_HOURS):
  → Fetch latest gold price from livepriceofgold.com
  → Save to shared price history table
  → For each user with Telegram connected:
       if (now − last_notified_at) ≥ user.notify_interval_hours (default 48h):
           Send periodic price summary  ◀ every 2 days
       For each active alert rule:
           if rule condition met → send alert immediately
```

Users set their own interval (1–8760 h) in Settings. Default is 48 h (every 2 days).

## API Reference

### Auth
| Method | Path | Auth | Description |
|--------|------|------|-------------|
| POST | `/api/auth/register` | — | Create account |
| POST | `/api/auth/login` | — | Get JWT token |
| GET | `/api/auth/me` | ✓ | Current user |
| PUT | `/api/auth/me` | ✓ | Update name / interval |
| GET | `/api/auth/telegram/link` | ✓ | Generate Telegram deep-link |
| DELETE | `/api/auth/telegram/unlink` | ✓ | Disconnect Telegram |

### Prices
| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/api/prices` | — | Paginated price history |
| GET | `/api/prices/latest` | — | Most recent record |
| POST | `/api/prices/fetch` | ✓ | Manual fetch + notify |

### Alerts
| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/api/alerts` | ✓ | Your rules |
| POST | `/api/alerts` | ✓ | Create rule |
| PUT | `/api/alerts/{id}` | ✓ | Update / toggle |
| DELETE | `/api/alerts/{id}` | ✓ | Delete rule |

### System
| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/health` | Health check |
| GET | `/ping` | Keep-alive (used by GitHub Actions) |
| POST | `/api/telegram/webhook` | Telegram bot receiver |
